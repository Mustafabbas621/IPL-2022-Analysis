# IPL 2022 Capstone Project

Exploratory data analysis of match-level data from the 2022 Indian Premier League (IPL) season, covering match outcomes, player performances, and venue trends.

## Questions Explored

**Team & match trends**
- Which team won the most matches?
- How do toss decisions trend (bat vs. field)?
- How often does the toss winner also win the match?
- Do teams tend to win by runs or by wickets?

**Player performances**
- Most "Player of the Match" awards
- Top scorers
- Best bowling figures

**Venue analysis**
- Which venues hosted the most matches?

**Custom insights**
- Largest win margin by runs
- Highest individual score
- Best bowling figures of the season

## Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook


## How to Run
1. Clone the repo:
   ```bash
   git clone https://github.com/Mustafabbas621/ipl-2022-analysis.git
   cd ipl-2022-analysis
   ```
2. Install dependencies:
   ```bash
   pip install numpy pandas seaborn matplotlib jupyter
   ```
3. Place `IPL.csv` in the project folder and launch the notebook:
   ```bash
   jupyter notebook IPL_Capstone_Project.ipynb
   ```
